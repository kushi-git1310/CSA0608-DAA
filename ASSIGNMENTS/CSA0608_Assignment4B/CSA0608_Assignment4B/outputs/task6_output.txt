##############################################################################
TASK 6.1 / 6.2  MODEL AND DP STATE
##############################################################################
Input     : (n+1)x(n+1) cost matrix, hub = index 0
Output    : closed tour Hub -> all n locations once -> Hub, and its total cost
Objective : minimise total travel cost
Constraints: each location exactly once; start and end at the hub; costs non-negative
State     : DP[S][j] = cheapest way to leave the hub, visit exactly the set S, finish at j (j in S)
Base      : DP[{j}][j] = cost[Hub][j]
Recurrence: DP[S][j] = min_{k in S-{j}} ( DP[S-{j}][k] + cost[k][j] )
Final     : OPT = min_j ( DP[ALL][j] + cost[j][Hub] )
Why 'current location' alone is not enough: Hub->A->B->C and Hub->B->A->C both end at C but
have visited the same SET in different orders with different costs; two partial routes are
comparable only if they have the same visited set AND the same current location.
